# YouTube Upload Kit

## Channel setup (do once, ~10 min)
Your current channel is **@RealMGGaming**. Gaming viewers won't watch ML lessons, and YouTube's
algorithm gets confused by mixed topics. Make a **second channel on the same Google account**:

1. YouTube → profile picture → **Settings** → **Add or manage your channel(s)** → **Create a channel**.
2. Name ideas: **ML From Scratch with Sogol**, **Sogol Codes ML**, **TensorByTensor**.
3. Handle: e.g. `@MLFromScratchSogol`.
4. Description (paste):
   > Machine learning algorithms explained from scratch, in plain Python and NumPy. One algorithm a
   > week: softmax, loss functions, gradient descent, neural nets, attention. By a University of
   > Malaya student. Free notes & code: https://github.com/mqadimimehr-hash/TensorTonic-Solutions/tree/main/content
   > Need tutoring? Contact me: (add a contact email here)

## How to record (free)
- **Screen:** OBS Studio (free) or Windows `Win + Alt + R`. Record VS Code with a 20pt+ font.
- **Vertical Shorts:** edit in CapCut (free) → canvas 9:16 → add auto-captions.
- **Voice:** your phone mic held ~20 cm away in a quiet room is enough.
- **Upload:** YouTube Studio → Create → Upload → paste title and description from above.
